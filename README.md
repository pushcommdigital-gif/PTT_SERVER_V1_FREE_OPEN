# PTT_SERVER_V1_FREE_OPEN
A free, self-hosted push-to-talk platform that turns any Android phone or rugged radio into a business PTT device over cellular or Wi-Fi — no per-seat fees, no user caps, no strings.

Run a real dispatch operation from day one: live push-to-talk, a real-time map of your team, a browser-based dispatch console, messaging, and safety features — all on your own server.

Features
 Push-to-talk voice — group channels, all-call, private 1:1, half-duplex floor control (LiveKit SFU)
 Live map — real-time GPS positions of every unit
 Dispatch console — floating panels, follow-the-talker, multi-monitor
 Messaging — direct messages and conversations
 SOS / Lone Worker — one-tap emergency + check-in safety
 Geofences, zones & POIs — with entry/exit alerts
 Call recording & CDR — every transmission captured and searchable
 Android app +  web dispatch & admin dashboard
 Self-hosted — bring it up with Docker Compose in minutes
Open core
PushComm CE is the open-source core of the commercial PushComm platform. Advanced add-ons — voice transcription, snap-to-road telematics & driver scorecards, live traffic, visual verification, OTA fleet updates, and managed hosting/SaaS — are available separately. Everything in this repository is free and always will be.
